## 🚀 Featured Projects

<details open>
<summary><b>📊 ByteBoom AI — Crypto Market Intelligence Platform</b></summary>
<br/>

Production system built around **9 independent microservices** — TA, Secret Formula, VLM, Whale, Liquidations, Flow, ETF, News, and Macro — fused into unified trading signals.

- MCP server wraps existing REST endpoints for multi-agent orchestration, no changes to underlying services
- GraphRAG layer for internal signal fusion across all 9 services
- Currently building: Signal Expiry & Buy Tracking — atomic race-condition handling, SQL schema, worker architecture
- Automated trading bot layered on top of the signal stack

`Python` `FastAPI` `PostgreSQL` `Redis` `Docker` `MCP`

</details>

<details>
<summary><b>🧠 MCP Orchestration Server</b></summary>
<br/>

Multi-agent orchestration layer that replaces a monolithic GraphRAG approach with **deterministic, confidence-scored signal fusion** across independent AI services.

`Python` `MCP` `LangChain`

</details>
